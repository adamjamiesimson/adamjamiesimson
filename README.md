## About

I’m an engineering student and independent researcher based in Dubai. I build thoughtful, practical technology where **AI, accessibility, science, and learning** meet.

- **[BookQuest](https://bookquestgame.vercel.app)** — co-founding an interactive, game-based learning platform.
- **[MS-MLB](https://arxiv.org/abs/2608.05196)** — co-author of open machine-learning research on blood-based multiple-sclerosis classification.
